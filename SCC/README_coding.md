




# ⚠️ Minor differences to be aware of
Feature	cmd	PowerShell
Virtual env activation	.venv\Scripts\activate	same
Set environment var	set VAR=value	$env:VAR="value"
List files	dir	ls or dir
Copy/paste	Right-click or Ctrl+C/Ctrl+V (enable in properties)	Ctrl+Shift+C/V
Command history	doskey /history	Get-History or up/down arrows
But for 99% of Django work, the commands are identical. The framework doesn’t care which shell you use.

🎯 Core Goals of the Icon Grid
1. Zero reading, instant understanding
In a crisis, reading takes too long and can be confusing. Icons speak to everyone, regardless of language, age, or literacy. A flame means fire, a star of life means medical – no translation needed.

2. One-tap action
Each icon is a large, tappable button. No menus, no scrolling, no “are you sure?” The user taps the icon that matches what’s happening, and the app immediately knows whether to call 911, 211, or trigger a specific emergency protocol.
